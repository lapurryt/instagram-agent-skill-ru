# ig-ru

Пакет из 13 скиллов для Instagram на русском, с добавками из нашей ниши. Каждый скилл лежит в
`skills/<имя>/SKILL.md`, рядом его скрипты и данные (`_ru`).

Отвечай по-русски, коротко, простыми словами.

## Как пользоваться

1. По запросу выбери скилл из таблицы.
2. Прочитай его `skills/<имя>/SKILL.md` целиком и делай по нему. Claude Code видит их и как отдельные скиллы
   `ig-ru:ig-reel`, `ig-ru:ig-human` и т.д., их можно звать через Skill. Запись
   `/ig-human` внутри файлов значит этот же скилл пакета.
3. Скрипты запускай `python -I -X utf8 <путь к скрипту>`. Зависимостей и сети нет, всё работает на этом компьютере.

## Тринадцать

| скилл | что делает |
| --- | --- |
| `/ig-reel` | Идея в рилс. Три хука из [29 формул](skills/ig-reel/hooks_ru.json) с оценкой, сценарий, надписи на экране и биты по секундам |
| `/ig-viral` | Ищет, что работает в нише, сортирует по множителю над медианой каждого аккаунта, называет формулу, пишет свайп-файл |
| `/ig-caption` | Подпись с линтером. Показывает 125 знаков, которые лента показывает до «… ещё» |
| `/ig-carousel` | Карусели. Обложка, которая заставляет листать, текст слайдов, файлы 1080×1350 |
| `/ig-story` | Сторис на день, какой стикер для чего, воронка в директ, где первым пишет зритель |
| `/ig-profile` | Оценка профиля по [12 пунктам](skills/ig-profile/rubric_ru.json) из 100, переписывает по порядку важности |
| `/ig-plan` | Неделя: что выложить, в каком формате, когда, и 10 аккаунтов для общения |
| `/ig-human` | Очеловечиватель. Два скрипта, которые правда работают, и русский словарь штампов |
| `/ig-comment` | Комментарии под чужими постами. Девять типов, по тому, что за пост. Никогда «🔥🔥🔥» |
| `/ig-reply` | Ветка под своим постом. Раскладывает на кодовое слово / лид / по делу / вопрос / поддержка / шум и отвечает в этом порядке |
| `/ig-dm` | Выдача по кодовому слову, первое сообщение, предложение о соавторстве и два дожима. Два |
| `/ig-repurpose` | Одно видео, подкаст или рассылка в неделю рилсов и каруселей, каждый сам по себе |
| `/ig-audit` | Разбор уже выложенного. Рейтинг по множителю и отправкам на охват, а не по просмотрам |

## Инструменты, которые запускаются

```
skills/ig-reel/hookscore_ru.py      оценка хука по 6 проверкам, шестая ВЫГОДА
skills/ig-reel/beats_ru.py          сценарий в биты по секундам, 195 слов в минуту
skills/ig-caption/caption_ru.py     что видно до «… ещё» и линтер подписи
skills/ig-human/humanize_ru.py      три прохода чистки: невидимые символы, типографика, штампы
skills/ig-human/detect_ru.py        пять проверок на «машинность»
skills/ig-viral/swipe_ru.py         рейтинг по множителю и формула хука
```

Данные: `skills/ig-reel/hooks_ru.json` (29 формул и 4 антиформулы), `skills/ig-reel/calibration.md` (насколько
оценщик хука вообще что-то предсказывает), `skills/ig-human/slop_ru.json` (словарь штампов),
`skills/ig-profile/rubric_ru.json` (профиль из 100), `templates/voice.md` (голос автора, заполнить первым,
положить в `~/.claude/instagram/voice.md`).

Старые пути `hookscore_ru.py` и `beats_ru.py` в корне пакета оставлены как переходники: они запускают файлы из
`skills/ig-reel/`. Новые команды пиши с новым путём.

## Правила всего пакета

- **Ничего не публикуется, пока ты не сказал «да».** Скиллы пишут, выкладываешь ты. Никакой браузерной автоматики
  на аккаунте: Instagram за неё ограничивает действия.
- **Ничего не выдумывается.** Нужна цифра, которой нет: `{{цифра}}` и отметка. Факты сверяются на первоисточнике в
  тот же день.
